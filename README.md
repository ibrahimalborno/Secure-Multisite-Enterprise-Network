# Secure Multi-Site Enterprise Network

This project is a hands-on enterprise networking lab built to simulate a company with a headquarters, two branch offices, and hybrid cloud connectivity.

The network will include routing, VLAN segmentation, firewalls, site-to-site VPNs, monitoring, automation, and failure testing.

## Project Status

In Development

## Planned Architecture

- Headquarters
- Branch Office 1
- Branch Office 2
- Hybrid Cloud Environment
- VLAN Segmentation
- OSPF Dynamic Routing
- Stateful Firewalls
- Site-to-Site IPsec VPNs
- NAT / PAT
- High Availability
- Centralized Monitoring
- Network Automation
- Failure Testing and Troubleshooting

## Goal

The goal of this project is to build a realistic enterprise network from the ground up and gain practical experience with network design, routing, security, troubleshooting, monitoring, and automation.

Configurations, diagrams, screenshots, testing results, packet captures, and documentation will be added as the project is built.
